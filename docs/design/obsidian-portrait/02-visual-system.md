# 02 · 曜黑极简视觉系统

## 1. 视觉主张

以用户选定的 D 首页为唯一方向：安静的黑灰层级承托封面，冰青只用于主要操作、当前选择、进度和焦点。页面内容优先，使用中等圆角、整齐边距、清楚的中文层级。保留主机菜单的选择感，按手机竖屏重新安排触控和滚动。

首页的记忆点是“大主卡 + 继续/管理 + 其他游戏小卡”。发现页改为两列目录；详情使用纵向信息和底部固定操作；下载和设置用可读行列表。全套共用组件，不把每个页面设计成新的主题。

## 2. 颜色令牌

机器可读规范：[tokens.json](data/tokens.json)。实现应使用语义名称，不逐页散落颜色常量。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| background | `#101317` | 页面底色和系统栏背景衔接 |
| surface | `#1B2128` | 普通卡片、列表组、输入区域 |
| surfaceRaised | `#242C35` | 弹层、短提示、抬高一级的表面 |
| borderSubtle | `#303943` | 分隔和装饰轮廓，不独自承担控件识别 |
| borderControl | `#647888` | 需要明确识别的输入、次按钮和控件边界 |
| textPrimary | `#F0F4F7` | 标题、重要信息、普通正文 |
| textSecondary | `#9EAAB5` | 说明、标签、次要信息 |
| textMuted | `#8997A4` | 低强调但仍需阅读的补充文本 |
| textDisabled | `#657381` | 不可操作状态，并同时提供禁用语义和原因 |
| accent / onAccent | `#81D8DF` / `#102226` | 主要按钮、焦点、进度及其深色文字 |
| accentPressed | `#68C0C8` | 主要操作按下反馈 |
| success / warning / error | `#92D8AD` / `#E8C47E` / `#F0A6A6` | 状态文本与图标，始终配可读原因 |

不采用纯白大面板、全屏氛围插画、实时玻璃模糊、持续发光、主题自动换色或动态壁纸。当前只设计暗色基线，系统浅色模式不改变已选风格；系统弹窗仍保持平台实际样式。

颜色对比按实际前景/背景计算，实测结果见 [检查记录](10-review-report.md)。普通文本目标至少 4.5:1；有意义的控件边界和焦点按 3:1 检查。细分隔线允许低强调，但不能成为唯一的信息或交互线索。

## 3. 字体与数字

| 用途 | 字号 / 行高 | 字重 | 规则 |
| --- | --- | --- | --- |
| 页面标题 | 28 / 36 sp | 700 | 每页一个主标题，中文不强行紧缩字距 |
| 区块标题 | 20 / 28 sp | 650 | 分组用真实内容名，不用装饰编号 |
| 游戏/列表标题 | 18 / 26 sp | 650 | 可换行，详情中可获得完整名称 |
| 正文 | 16 / 24 sp | 400 | 说明清楚、短句、避免工程参数堆积 |
| 标签/次要信息 | 14 / 20 sp | 500 | 状态、时间、大小等 |
| 辅助说明 | 12 / 18 sp | 400 | 仅低优先级说明，不能承载唯一错误原因 |
| 按钮 | 16 / 24 sp | 650 | 动词明确，允许放大后换行 |

Android 优先使用系统中文无衬线及系统回退；没有必须在线下载的字体。NsA 工作标识可单独绘制，中文正文仍走平台文字。百分比、速度、容量和时间使用等宽数字；未知总量/速度/ETA 不伪造精度。

## 4. 栅格、尺寸和间距

基础参考为 393dp 宽手机；同时检查 360、412 和 600 宽窗口。参考高度 852 只用于原型审阅，不当成固定屏幕高度。布局使用真实窗口与安全区，页面内容允许纵向滚动。

| 项 | 规格 |
| --- | --- |
| 间距序列 | 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 dp |
| 手机内容边距 | 16dp；卡片内部通常 12–16dp |
| 区块间距 | 24dp；独立大段 32dp |
| 两列封面间距 | 12dp；首页三小卡间距 8dp |
| 主要按钮 | 最小 56dp 高；次按钮最小 48dp |
| 所有触控目标 | 至少 48×48dp，图标可为 24dp |
| 输入框 | 最小 56dp 高；字号放大后增长 |
| 顶部应用栏 | 基础 56dp，另加系统状态安全区 |
| 底部导航 | 基础 72dp，另加底部安全区；文字放大后自适应 |
| 设置行 | 最小 64dp；副标题/放大字体允许增长 |
| 平板内容 | 24dp 边距，正文/卡片主体最大 520dp 并居中 |

圆角：主卡 16、按钮 14、输入框 12、标签 8、底部面板 24dp。阴影只用于确认层与短提示分离；普通卡片主要依靠明度和边界，不堆叠阴影。

## 5. 页面骨架

```text
根页面                         二级详情/管理
系统状态安全区                  系统状态安全区
NsA / 玩家                     返回  页面名称
页面标题 / 搜索                  主体内容（纵向滚动）
主体内容（纵向滚动）             数据 / 说明 / 状态
所选游戏/目录/任务/设置           固定主操作（需要时）
四入口底部导航                  底部系统安全区
底部系统安全区
```

固定按钮和导航都占据真实布局空间；列表末项不能被覆盖。详情页无主导航，保留返回路径和固定主按钮。弹层有可见取消、清楚标题与影响范围；不同时叠加多个确认层。

## 6. 封面、图标与焦点

封面为虚构素材，沿用四个游戏的稳定身份。首页主卡可采用宽图；目录使用固定比例裁切，详情展示更宽的图。名称和状态放在真实文本区域，避免依赖封面里烘焙的字。封面缺失用同尺寸深色占位和名称，不显示裂图或改变列表高度。

图标采用统一线性矢量语言：24dp 画布、约 1.8dp 线宽、圆端点；同级不混用表情和不同粗细。当前位置同时有文字、图标与选中底色。键盘/手柄焦点使用独立冰青外框，不能覆盖“已安装/错误”等语义。

首页整张封面可点入详情，继续和管理是独立控件；不要把多个按钮嵌套在同一个按钮内。手柄焦点顺序与视觉顺序一致，长列表滚动后仍可找到当前焦点。

## 7. 动效与反馈

按下反馈约 100ms；小范围内容切换 160ms；面板进入 240ms、退出 160ms。它们是设计目标，实际手势响应优先。按下不改变布局尺寸，不播放与任务无关的庆祝动画。

进度变化从真实字节/阶段驱动；读取错误或任务暂停后停止假进度。等待动画不冒充可测百分比。减少动态效果时去掉位移和循环装饰，保留即时状态、文本与必要进度。进入游戏不增加额外品牌动画延迟。
