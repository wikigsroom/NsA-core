# 原型素材来源

本目录五张 WebP 从用户已选的 [D · 曜黑极简原图](../../hall-options/single-home-round-2/images/D-obsidian-portrait.png) 裁切，作为虚构游戏和游客头像的固定原型素材。具体坐标、尺寸、字节与 SHA-256 见 [manifest.json](manifest.json)。本轮没有从真实游戏包提取素材。

原图生成来源见 [第二轮生成记录](../../hall-options/single-home-round-2/generation-record.json)。本轮仅裁切并编码为 WebP；没有重新绘制或声称是正式游戏的授权美术。正式目录需用对应游戏发行所提供的可用封面、名称与归属信息替换。

原型内线性 SVG 图标直接定义于 app.js；品牌仅使用 NsA 工作文字。中文字体使用本机系统回退，无在线字体、外部图标脚本或热链素材。AI 视觉中的个别图标、头像及字距不应直接切片投入原生界面。
