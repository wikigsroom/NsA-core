## 已确定的设计

背景 `#101317`，卡片 `#1B2128`，冰青 `#81D8DF` 作为主要操作与焦点。保留参考首页的大主卡、最近游玩信息、继续/管理双操作和下方其他游戏卡。所有非游戏页面以手机纵向使用为主，四个主入口置底；二级页面使用返回导航，不叠加主导航抢占空间。

大厅、发现、搜索、详情、下载、校验、安装准备、存档、管理、设置和失败恢复均为竖屏。只有用户明确启动并进入实际运行界面才横屏。游戏内暂停和退出确认跟随横屏；正常退出、取消或失败返回后恢复竖屏及来源页面状态。后台下载完成不会自动拉起游戏。

## 交付的使用边界

文档、设计数据与可点击原型构成可交付的设计基线。原型使用虚构游戏、固定样例数据和手动推进的演示任务，不连接下载服务、不执行原生游戏、不修改手机。关键视觉扩展用实际图像生成服务制作；精确布局、组件、按钮条件和文字以本设计文档及规范原型为准。

Android 原生页面、下载服务、真实存档事务和真机方向切换仍属于后续实现与验收。本站点的横屏预览表示界面边界，不能作为手机游戏已运行或达到性能门槛的证据。
