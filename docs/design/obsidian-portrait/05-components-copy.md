# 05 · 组件、状态与中文文案

## 1. 统一组件目录

所有组件使用 [视觉令牌](data/tokens.json)。属性是设计与研发的语义契约，不限定 Kotlin 类名。页面不得自行添加一套同义状态。

| ID / 组件 | 必要输入 | 状态与交互 | 输出/验收重点 |
| --- | --- | --- | --- |
| C01 系统安全区槽 | 顶/底/键盘实际 inset | 系统状态栏与手势区由系统提供 | 不重复绘制假系统栏；原型状态栏仅占位 |
| C02 品牌与玩家 | 工作标识、游客头像/名称 | 名称可放大，头像不是强制登录入口 | NsA 字标一致，不使用主机厂商标识 |
| C03 顶部应用栏 | 页面名、返回来源、可选次操作 | 返回至少 48dp，标题可增长 | 返回到来源，不遮系统栏 |
| C04 底部四入口 | 当前标签、未完成任务数 | 当前状态、按下、键盘/手柄焦点 | 顺序固定，图标与文字并存，角标有语义 |
| C05 搜索框 | 范围、查询、提交/清除事件 | 空、输入、搜索、错误；明确可访问标签 | 不只靠占位符做标签；保留查询 |
| C06 筛选标签组 | 可见选项、当前选择 | 选中/未选、按下、焦点 | `selected` 语义，标签可换行，无横向强制拖动 |
| C07 封面卡 | 游戏 ID、封面、名称、支持/安装状态 | 默认、焦点、加载占位、缺图、阻断 | 点入详情；状态不烘焙在图上 |
| C08 首页所选主卡 | 所选游戏、存档摘要、主/次动作 | 已安装、下载中、损坏、阻断、有更新 | 主卡与标题/操作身份一致，子按钮独立 |
| C09 游戏摘要 | 封面、名称、有效版本 | 未安装/有效/正在运行 | 管理、存档和任务中复用，不复制事实 |
| C10 状态标签 | 文案、语义、可读原因 | 成功/等待/实验/错误/未知 | 图标+文字，不能仅靠颜色 |
| C11 主要按钮 | 文案、可执行性、事件、忙碌状态 | 默认/按下/焦点/忙碌/禁用 | 56dp；忙碌防重复；禁用原因附近可见 |
| C12 次按钮/图标按钮 | 文案或可访问名、事件 | 默认/按下/焦点/禁用 | 最少 48dp；图标按钮不能无名 |
| C13 下载任务卡 | 任务/版本 ID、阶段、字节、速度、原因 | 排队/传输/暂停/等待/校验/失败 | 控制同一任务；不允许未就绪的开始按钮 |
| C14 进度 | 可测总量与已完成量/不可测阶段 | 确定/不确定/暂停/失败 | 不确定阶段无虚假百分比；读屏包含阶段 |
| C15 信息定义行 | 字段名、实际值、单位、可选详情 | 正常/未知/多行 | 64 位数据格式化；未知写暂不可用 |
| C16 设置行 | 名称、说明、当前值、目的地 | 可进入/不可用/需处理 | 整行触控，长文本增长，状态由数据刷新 |
| C17 开关/选择/滑杆 | 标签、值、范围、保存状态 | 开/关/不可用/保存失败 | 不同控件语义正确；保存失败回真实值 |
| C18 底部面板 | 标题、内容、动作、来源焦点 | 打开/关闭/提交中 | 可见取消、遮罩、焦点约束、返回恢复 |
| C19 风险确认 | 对象、范围、影响、保留数据 | 允许/运行中阻止/处理中 | 安全动作清楚，删除存档非默认 |
| C20 内联提示 | 原因、语义、下一步 | 离线/等待/失败/恢复中 | 与受影响内容相邻，保留旧内容 |
| C21 空状态 | 原因、解释、可执行动作 | 首次为空/筛选为空/无缓存/无存档 | 不伪造最近记录，给符合当前权限的动作 |
| C22 加载占位 | 预计内容结构、请求状态 | 首屏/分页/更新 | 保留卡片尺寸；不无限遮住缓存内容 |
| C23 短提示 | 结果、可选撤销、关闭 | 成功/失败/等待确认 | 不遮主要焦点；长期问题另有页面记录 |
| C24 表单字段 | 标签、值、约束、错误、帮助 | 正常/焦点/输入错误/提交中 | 就地错误、保留草稿、可选字段明确 |
| C25 存储摘要 | 总量、可用、各类别实际字节 | 正常/不足/未知 | 文本值完整，图仅辅助，系统其他单列 |
| C26 存档/备份行 | 游戏、版本、时间、大小、兼容性 | 可导出/运行中限制/不兼容/失败 | 明确已提交记录和替换影响 |

## 2. 控件的共同状态

默认与按下保持相同布局尺寸。按下立即改变表面/明度；焦点有独立轮廓。忙碌状态保留原操作语义并防重复，但用户仍能看见当前阶段和退出/返回路径。禁用控件使用真实禁用语义，文字说明为何不能操作；不能只降低透明度。

选中表示当前标签/筛选/游戏，不等于已安装或可玩。暂停表示任务可恢复，不等于失败。列表载入、应用离线与游戏不支持也应分别表达。

## 3. 标准用词

| 情境 | 使用 | 不承诺的含义 |
| --- | --- | --- |
| 取得内容 | 下载游戏 / 继续下载 | 不把文件传完称为已可玩 |
| 安装中 | 正在校验文件 / 正在准备游戏 | 无测量时不用虚构 99% |
| 安装有效 | 开始游戏 | 仍需要本次启动检查 |
| 有已提交进度 | 继续游戏 | 不表示任意内存快照恢复 |
| 同一会话运行 | 返回游戏 | 不新开进程 |
| 删除资源 | 删除游戏资源，默认保留存档 | 不等于卸载整个 App |
| 导出 | 导出备份 | 系统位置确认完成后才显示成功 |
| 失败 | 原因 + 已保留数据 + 下一步 | 不写“未知错误，请稍后”作为唯一说明 |

研发应以资源键引用，动态参数只填入已验证的值。大小、百分比、时间和任务数从状态层格式化，不在各页自行推测。正式支持多语言前保留键值结构，避免拼接句子或把中文绘入图片。

## 5. 内容约束

真实产品标识、包名、发布版本、隐私/服务条款、联系渠道和许可清单在发布前替换为实际资料。设计中的玩家、游戏、容量、版本、问题编号都是示例；四个虚构游戏不能变成平台真实内容供给或设备兼容承诺。

生成图片只提供视觉方向，AI 图中文字、图标与封面不会直接切图作为 Android 控件。系统权限、文件选择器、APK 安装确认走真实系统界面；设计中只定义调用前后的解释、取消和恢复。
