# 可离线审阅的完整原型

直接用本机浏览器打开 [index.html](index.html)。无需服务、账号、网络和依赖安装。所有数据与图片均从同一设计目录加载，不请求远程服务。

左栏选择 32 个页面；右栏选择该页状态、360/393/412/600 宽度及 100%/130%/200% 字号。预览内的按钮可以导航，右侧工具仅用于推进演示情境，不是玩家界面。

## 主流程

1. 点击“重置为首次下载”，从发现页选择“星环漫游”，点击下载并确认。
2. 每次点击“推进一步”，依次得到排队→64%→校验→准备→可开始。100% 下载完成仍不能跳过校验/准备。
3. 点击开始先进入竖屏启动检查，再推进才出现横屏运行边界。暂停→返回大厅→确认后恢复竖屏。
4. 也可恢复选定首页，启动已安装的“远野回声”。其运行时“星环漫游”任务自动暂停，退出/演示中断后恢复；手动暂停的任务保持暂停。
5. 查看资源删除、存档不兼容、计费网络确认、帮助表单、离线和更新状态。工具重置会恢复全部虚构数据。

## 页面链接与数据

`index.html?screen=S03&state=unsupported` 可直接打开指定状态。`capture=1` 隐藏审阅工具，便于检查单张规范画面。S09/S10/S11 为游戏运行边界，其他页面为竖屏。

设计数据源为上一级 data 目录；design-data.js 是相同数据的本地脚本包装，避免 file:// 下 fetch 限制。修改令牌/目录/样例后需同步包装。app.js 的 `window.NSAPrototype` 只供审阅，不是客户端正式 API。

## 模拟范围

下载、校验、运行、反馈回执、导出及系统安装等为显式演示，不发生真实传输、APK 安装、手机写入或存档事务。示例反馈回执并不代表服务实际收到问题。预览内的状态栏只展示安全区关系，正式产品由 Android 系统绘制。

原型不存储用户真实资料；刷新或重置可清空。系统权限、通知、文件选择器、TalkBack、进程回收和 USB 真机方向行为需在原生版本验收。检查结果见 [本轮报告](../10-review-report.md)。
