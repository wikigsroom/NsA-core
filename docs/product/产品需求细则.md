## APP · 应用身份与首次使用

<a id="app-01"></a>
### APP-01 · P0

一个固定包名、一个桌面入口；大厅和游戏属于同一安装包。首次测试旧单游戏 App 的包名不直接作为正式产品身份；正式包名与签名在发布前确定。

责任：Android。页面：[S00](../design/obsidian-portrait/03-screen-specs.md#s00)、[S23](../design/obsidian-portrait/03-screen-specs.md#s23)。

| 规则 | 必须满足的行为 |
| --- | --- |
| APP-01.01 | 发布使用固定 applicationId、单个桌面入口和同一签名谱系；调试包以独立后缀区分，不能覆盖发行包。 |
| APP-01.02 | 大厅与 RuntimeActivity 必须属于同一 applicationId，下载内容不得要求安装第二个游戏 APK。 |
| APP-01.03 | versionCode 严格递增；改名不改变 game_id、本地存档身份或签名。 |
| APP-01.04 | 开发包、旧单游戏包和正式包的数据迁移必须经用户导出/导入，不直接跨私有目录读取。 |

验收：AC-A01；工作项：T-05、T-22。实现前核对关联技术章与页面条件；结果登记在版本验收记录，不能把“预期”改成无证据“通过”。

### APP-02 · P0

全新安装后可直接进入游客大厅；开放内容下载和游玩不被强制注册阻断。若某内容需要账号授权，只在该内容入口说明并验证。

责任：Android。页面：[S00](../design/obsidian-portrait/03-screen-specs.md#s00)、[S01](../design/obsidian-portrait/03-screen-specs.md#s01)。

| 规则 | 必须满足的行为 |
| --- | --- |
| APP-02.01 | 首次启动完成必要提示后提供游客进入，不先要求手机号、付费、导入文件或启用 USB 调试。 |
| APP-02.02 | 开放内容的浏览、下载、安装和离线启动在游客身份下闭环；内部匿名安装凭证不是用户注册账号。 |
| APP-02.03 | 确需资格的内测内容在详情说明原因；资格失效只影响对应内容，不清空其他已安装游戏。 |
| APP-02.04 | 首次完成标志与权限选择分开保存；进程中断后恢复未完成步骤，不能循环强制看引导。 |

验收：AC-A01；工作项：T-05。实现前核对关联技术章与页面条件；结果登记在版本验收记录，不能把“预期”改成无证据“通过”。

责任：Android。页面：[S25](../design/obsidian-portrait/03-screen-specs.md#s25)、[S04](../design/obsidian-portrait/03-screen-specs.md#s04)、[S15](../design/obsidian-portrait/03-screen-specs.md#s15)。

| 规则 | 必须满足的行为 |
| --- | --- |
| APP-04.01 | 私有目录下载和安装不申请全部文件访问权限；通知在用户发起任务时解释用途。 |
| APP-04.02 | 拒绝通知后保留 App 内任务中心；按平台允许的执行机制运行，不能伪造已获授权。 |
| APP-04.03 | 导入/导出调用系统文件选择器；取消或权限撤回不删除原档。 |
| APP-04.04 | 权限永久拒绝显示前往系统设置的操作，返回后重新读取实际权限，不靠按钮点击自改状态。 |

验收：AC-A03；工作项：T-05、T-10。实现前核对关联技术章与页面条件；结果登记在版本验收记录，不能把“预期”改成无证据“通过”。

## CAT · 目录、搜索与兼容

<a id="cat-01"></a>
### CAT-01 · P0

服务端维护有发布状态的游戏目录；用户只获得其发行区域、内容范围和测试资格允许看到的条目。原始 profile 目录不能直接等同公开目录。

责任：Android / 目录服务。页面：[S01](../design/obsidian-portrait/03-screen-specs.md#s01)、[S03](../design/obsidian-portrait/03-screen-specs.md#s03)。

| 规则 | 必须满足的行为 |
| --- | --- |
| CAT-01.01 | 目录服务按渠道、区域、资格和发布状态生成可见集合；生产客户端不暴露草稿。 |
| CAT-01.02 | 列表固定快照和游标分页；同一快照内 game_id 唯一，新增发布通过刷新进入。 |
| CAT-01.03 | 卡片最少包含稳定 ID、名称、封面、类型、可见发行、本机支持摘要及主状态。 |
| CAT-01.04 | 封面缺失采用同尺寸占位并保留名称；素材失败不阻塞整页及已安装入口。 |

验收：AC-C01；工作项：T-06。实现前核对关联技术章与页面条件；结果登记在版本验收记录，不能把“预期”改成无证据“通过”。

| CAT-02.02 | 搜索提交使用独立请求 ID，迟到的旧响应不能覆盖新查询；清空后恢复当前筛选。 |

| CAT-05.02 | 结果绑定 release、App 构建、模块、驱动、GPU/系统及能力条件，不能只按手机品牌判定。 |
| CAT-05.03 | 未命中规则默认 unverified；服务结果仍由本地硬能力检查覆盖，二者冲突保守处理。 |

验收：AC-C03；工作项：T-01、T-06。实现前核对关联技术章与页面条件；结果登记在版本验收记录，不能把“预期”改成无证据“通过”。

### CAT-06 · P0

只有可公开分发、内容包完整且存在匹配运行模块的版本可供正式下载。缺少对应模块时显示“更新 App 后可下载”，不先下载十几 GB 再告知无法启动。

责任：Android / 目录服务。页面：[S03](../design/obsidian-portrait/03-screen-specs.md#s03)、[S22](../design/obsidian-portrait/03-screen-specs.md#s22)。

| 规则 | 必须满足的行为 |
| --- | --- |
| CAT-06.01 | 正式下载需同时满足可见范围、可分发状态、已签名完整包、内置运行模块与已验证设备条件。 |
| CAT-06.02 | 仅内部测试可按资格开放 experimental；未验证不能通过忽略对话框自动变为正式可玩。 |
