# NsA 游戏大厅二次开发文档

版本：需求基线草案 v1.1；日期：2026-11-06（UTC+08:00）。

用户目标是：**安装一个 App，在游戏列表找到目标，点击下载，在这个 App 内加载并游玩。**

本目录将这个目标展开为可评审、可排期、可验证的产品需求。这里描述的是待开发能力；现有《旷野之息》真机验证不等于大厅、下载服务或统一运行入口已经实现。

阅读顺序：先确认需求说明书中的产品边界，再看技术方案，最后按验收矩阵拆任务。功能编号用于跨文档追踪，不表示功能已经开发完成。

最新视觉探索见 [五套暗色竖屏大厅选型 D–H](../design/hall-options/single-home-round-2/README.md)。暗色调和默认竖屏已由用户确认，具体风格待选；原 A/B/C 横屏方案仅保留为历史视觉参考。

已确定的基础：

- 大厅、详情、下载、准备、设置和管理默认竖屏；仅启动具体游戏并进入运行界面后横屏，返回大厅恢复竖屏和原状态。大厅采用暗色调。

- 开发仓库：[wikigsroom/NsA-core](https://github.com/wikigsroom/NsA-core)，SSH 地址 `git@github.com:wikigsroom/NsA-core.git`。
- 上游参考：[shirai91/nx2android](https://github.com/shirai91/nx2android)；本次阅读的本地源码基线为 `a8adac18b947cc8a0969bd15e039f8cde754293a`，另有本地真机适配修改。
- 全部新增工程、构建、下载与缓存位于 `E:\dev\sandbox\游戏移植`。不调用本地 Docker、WSL 或其他虚拟化环境，设备验收使用 USB 真机。
- 后续工程、配置、测试和必要文档统一进入 NsA-core；游戏本体、密钥、工具链和生成产物继续遵守 `.gitignore`，不作为源码提交。

尚需评审的默认方案：首发采用官网 APK 分发；Android 原生大厅；随 App 内置少量已适配游戏的运行模块；在线交付已制作好的游戏内容包；游客可浏览与使用开放内容；先打通两款真实游戏切换，再扩大目录。它们是本文建议，并非用户已经逐项确认的商业决策。

特别需要先解决的两件事：

1. 同一 APK 内按游戏选择编译配置不同的运行模块，且退出或崩溃后大厅仍能恢复。
2. 公布下载的每款内容同时具备可分发来源、完整内容包、匹配运行模块和对应设备的可玩证据。

《旷野之息》当前在 Snapdragon 865 / Adreno 650 手机上已进入复苏神庙，并验证触屏操作与存档写入；观察到约 7–13 FPS，仍有兼容告警。这个结果可作为内部整合样本，不能作为正式“流畅可玩”样板，也不能据此保证《王国之泪》或其他游戏在同一手机上的表现。
