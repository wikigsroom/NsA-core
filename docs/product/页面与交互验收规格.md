# 页面与交互验收规格

基线 v2.0 · 2026-11-06。直接沿用定稿的 32 页、73 个典型命名状态；逐页视觉以 [定稿规格](../design/obsidian-portrait/03-screen-specs.md) 为准。本文件补足数据来源、命令、防重、边界和恢复，作为研发行为约束。

原型中的演示 task/state 名不是生产枚举；生产枚举统一见 [状态契约](../engineering/contracts/state-machines.json)。系统权限、文件选择器和原生游戏画面由相应系统/运行层提供。

## 全局执行约束

所有页面以事实投影渲染；命令携带稳定对象 ID 和期望修订号，提交期间禁重复但不以按钮禁用代替后端/本地幂等。页面卸载不丢任务，重建不创造新会话。提示与错误关联实际对象，来源恢复含根标签、路由、游戏、查询与滚动锚点。

点击封面只到详情，下载确认不等于立即可玩；运行窗口接管才横屏；返回、失败和取消恢复竖屏。底部导航仅根页面，二级页保持真实返回。通用 Loading/Empty/Error、系统对话框和确认组件属于页面状态，不为每个瞬时状态另建根页。

## 必须补齐的组件交互状态

以下细节扩展既有组件及页面状态，沿用 D 的颜色、字号、边距与按钮语义；不改变已选风格或根导航。原型的 73 个状态是典型组合，研发还必须实现下列瞬时、系统及事务状态。

| 编号 | 所在页 | 具体交互与验收 |
| --- | --- | --- |
| INT-01 | S17 | 触屏布局编辑：竖屏页内展示等比例控制预览；拖动/缩放外也有可访问的位置/尺寸调整；应用、取消、重置确认分开；离页有未保存草稿时确认；写入失败保留草稿。 |
| INT-02 | S15 | 删除存档确认显示游戏、最近提交、大小和不可恢复影响；默认焦点在保留；运行/导入/导出时禁覆盖；取消不改任何档。 |
| INT-03 | S15–S16 | 文件选择、解析、预检、备份、交换、成功、失败分别有状态；SAF取消不弹成功；空间不足不开始覆盖；失败仍有原档。 |
| INT-04 | S05/S13/S14 | 取消下载、清缓存、清临时分别确认影响；处理中显示真实状态；未完成清理显示残留，不报已释放。 |
| INT-05 | S11 | 正常退出超时后给等待和强制结束；强制结束再次说明未保存风险；不能无提示终止当前游戏。 |
| INT-06 | S21/S29 | 草稿离页确认、提交中防重、提交失败保留、诊断预览及真实回执；重试沿用同一幂等键。 |
| INT-07 | S22/S25 | 系统安装/权限请求可取消、拒绝、永久拒绝或稍后；App返回后读OS事实；禁止通过本地模拟布尔值标成功。 |
| INT-08 | S23 | 许可列表与具体正文可离线查看；来源链接有明确打开操作；产品名和归属来自实际发行配置。 |
| INT-09 | S05/S26 | 队列等待卡可见游戏、顺序、原因和取消；新版任务与旧可运行版同时存在时不混用按钮身份。 |
| INT-10 | S08–S12 | 迟到事件、系统回收、取消启动和旧session回调按session_id/revision隔离；方向变化只绑定本次活动会话。 |

实现这些状态时先补相应组件示例或原生预览，再按本表验证；不得用永久空按钮或虚假成功替代。若改变页面结构/主操作或新增商业流程，走 CR/ADR，不以内联补充默默扩大范围。
